## Summary
Qwen is the first installment of a comprehensive large language model series comprising base pretrained models (1.8B, 7B, and 14B parameters), chat models aligned with supervised finetuning (SFT) and RLHF (Qwen-Chat), and specialized coding (Code-Qwen) and math (Math-Qwen-Chat) models. The base models are pretrained on up to 3 trillion tokens of multilingual text and code. Qwen-14B outperforms previous 13B-scale open-source models on all seven reported base benchmarks and beats LLaMA2-70B on three. The chat models add tool-use, code-interpreter, and agent capabilities, with RLHF versions competitive on human evaluation but behind GPT-4.

## Background and Problem
Large language models have become versatile agents for conversation, code execution, and tool use, but leading models were criticized for their lack of reproducibility, steerability, and accessibility. The strongest models remained proprietary (GPT-3.5, GPT-4), while the strongest open-source models, LLaMA and LLaMA 2, still trailed them, and strong multilingual support, particularly for Chinese alongside English, was comparatively lacking. The report targets a competitive, open, Chinese-English model family at developer-friendly scales with alignment and agent abilities.

## Method
Qwen uses a modified LLaMA-style Transformer: untied input embeddings and output projection, rotary positional embeddings, biases added in the QKV attention layer, pre-normalization with RMSNorm, and SwiGLU activations. The three models use 2048-token contexts, AdamW with a cosine schedule decaying to 10% of peak, BF16 mixed precision, 4M-token batches, and 2.2T, 2.4T, and 3.0T training tokens respectively. Tokenization is BPE starting from tiktoken's cl100k_base, extended with Chinese words and characters to about 152K entries. Pretraining data mix public web documents, encyclopedia, books, and code, deduplicated, quality-filtered, and decontaminated against evaluation benchmarks. Alignment uses SFT on human-style conversations in ChatML format, a reward model built via preference model pretraining, and PPO with policy, value, reference, and reward models. Inference-time, training-free context extension combines NTK-aware and dynamic NTK interpolation, LogN-Scaling, and layer-wise window attention.

## Contributions
The report's contributions are: (1) open-sourcing 1.8B, 7B, and 14B base and chat models beating prior open models of similar size, with strong Chinese capability; (2) an SFT-plus-RLHF alignment pipeline yielding chat models with tool use, code interpreter, and agent skills; (3) specialized Code-Qwen models from continual pretraining on roughly 90B code tokens with 8192-token contexts, and Math-Qwen-Chat models; (4) public benchmarks for ReAct-style tool use and code-interpreter use; and (5) training-free context extension beyond 8K tokens.

## Experimental Setup
Base models were evaluated on MMLU (5-shot), C-Eval (5-shot), GSM8K (8-shot), MATH (4-shot), HumanEval (0-shot), MBPP (0-shot), and BBH (3-shot) against LLaMA, LLaMA 2, MPT, Falcon, Baichuan2, ChatGLM2, InternLM, and StableBeluga2. Long-context ability was measured by arXiv perplexity at 1024 to 16384 tokens. Aligned models were compared zero- and few-shot on the same benchmarks against GPT-3.5, GPT-4, LLaMA2-Chat, ChatGLM2, InternLM-Chat, and Baichuan2-Chat, plus a human evaluation on 300 Chinese instructions ranked against GPT-3.5 with GPT-4 as reference. Agent abilities used a ReAct tool-use benchmark, an in-house code-interpreter benchmark, and the Hugging Face Agent benchmark. Code-Qwen used HumanEval, MBPP, and HumanEvalPack; Math-Qwen-Chat used GSM8K, MATH, Math401, and Math23K.

## Results
Base Qwen-14B tops prior 13B SOTA on all seven benchmarks: MMLU 66.3, C-Eval 72.1, GSM8K 61.3, MATH 24.8, HumanEval 32.3, MBPP 40.8, BBH 53.4; Qwen-7B surpasses LLaMA2-13B and matches Baichuan2-13B. Context extension keeps arXiv perplexity between 3.18 and 3.42 at 8K to 16K tokens, versus hundreds to thousands without. Qwen-14B-Chat outperforms all aligned open models except ChatGPT and LLaMA2-Chat-70B, with 0-shot HumanEval of 43.9; human evaluation shows the RLHF model beating SFT versions but falling behind GPT-4. On the tool-use benchmark, Qwen-14B-Chat reaches 98% tool selection with 2.4% false positive error versus 85% and 75% for GPT-3.5. On the code-interpreter benchmark it achieves 81.7% overall correctness (GPT-3.5: 72.9%), and on the Hugging Face Agent benchmark 93.5% tool selection in run mode, close to GPT-4. Code-Qwen-Chat-14B reaches 66.4 pass@1 on HumanEval and 51.9 average on HumanEvalPack, beating similar-size baselines. Math-Qwen-Chat-14B reaches 69.8 on GSM8K and 24.2 on MATH, approaching GPT-3.5 (80.8 and 34.1) and beating Minerva-8B on MATH.

## Limitations
The base models still lag behind both GPT-3.5 and GPT-4, and human evaluation of the chat models shows them falling behind GPT-4. The authors note that traditional benchmarks cannot accurately measure aligned chat models, making the gap to proprietary models hard to capture. Code-Qwen and Code-Qwen-Chat fall behind state-of-the-art methods such as GPT-4, and Math-Qwen-Chat slightly trails proprietary models, chasing Minerva-62B and GPT-3.5. The in-house tool-use benchmark is described as relatively easy and requiring enhancement. Code-specialized models also do not necessarily outperform generalists on tasks like the code-interpreter benchmark requiring skills beyond code synthesis.
