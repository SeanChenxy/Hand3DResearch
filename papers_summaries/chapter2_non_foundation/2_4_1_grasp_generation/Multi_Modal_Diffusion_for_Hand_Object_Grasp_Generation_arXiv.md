# Multi-Modal Diffusion for Hand-Object Grasp Generation

**Authors:** Jinkun Cao, Jingyuan Liu, Kris Kitani, Yi Zhou  
**Date:** 2024-09-06  
**Identifier:** [arXiv:2409.04560](https://arxiv.org/abs/2409.04560)

## Summary

This paper proposes Multi-modal Grasp Diffusion (MGD), a latent diffusion model that treats hand pose and object shape as two jointly denoised modalities, so a single network can both sample a posed MANO hand together with an object (unconditional joint generation) and generate a grasp conditioned on a given object geometry. Its central idea is asynchronous denoising schedulers: the hand and object latent codes carry independent noise levels, which lets the model train on heterogeneous data sources with partial annotations (including object-only data without grasps) and condition on the object at inference by fixing its noise level to zero. Object encoding/decoding reuses LION point-diffusion networks pre-trained on more than 50,000 ShapeNet objects, giving a purely geometric, category-free object prior that generalizes far beyond the dozens-to-thousands of objects in hand-object interaction datasets. On OakInk-Shape test objects MGD reaches FID 20.73, penetration depth 0.32 cm, intersection volume 3.87 cm3, simulation displacement 2.52 cm, and user score 4.87/5, beating GrabNet and GrabNet-Refine; on ARCTIC objects unseen in training, adding object-only training data consistently improves all metrics.

## Background and Problem

The paper targets static hand grasp synthesis with universal generalization: instead of fitting a small set of objects from 3D hand-object interaction (HOI) datasets, it aims to generate plausible grasps for diverse and unseen object geometries, in a purely geometric way without language descriptions or category labels. Existing grasp generation methods depend on datasets with full-stack 3D annotations of both hand and object, and their annotations are locked to specific parametric hand models (e.g., MANO versus ShadowHand), which prevents combining data resources. Large-scale synthetic grasp datasets exist only for robotic hand models, while MANO-compatible datasets remain small and object-biased because scanning objects and capturing corresponding hand poses is expensive. The authors formulate two tasks: joint generation sampling from the hand-object distribution {O, H}, and object-conditioned generation sampling {H} given an object shape. Prior work had under-explored unconditional generation, and standalone conditional models are brittle to new object shapes. The key question is whether large-scale object-only 3D datasets can be exploited to relieve the HOI data bottleneck, by jointly modeling hand and object in a shared latent space while keeping modality representations decoupled enough for heterogeneous supervision. Two concurrent works are positioned against: UGG generates hand and object but uses the ShadowHand model and optimization-based results, and G-HOP requires a language prompt.

## Method

MGD follows the latent diffusion paradigm with x0-prediction: each modality is encoded into a latent code, noise is added via a Markov process, and a transformer encoder-only denoiser (following the human motion diffusion model MDM) predicts the clean latent. The hand is represented by MANO joint rotation angles theta in R48 plus translation (3-d), with a constant mean shape, concatenated into a 51-d vector and encoded by a 2-layer MLP (hidden 1024) to a latent z0_H in R1x512. The object is represented by its point-cloud latent (2,048 sampled points, object-centric frame), using LION's hierarchical latent point diffusion with the global latent code removed so shapes are encoded from pure geometry; the resulting object latent is z0_O in R4x512, and the concatenated interaction code is z0 in R5x512. The LION encoder and decoder are pre-trained on ShapeNet (more than 50,000 objects) and frozen, while the object prior distribution is fine-tuned on objects from GRAB, OakInk, AffordPose, and DexGraspNet (plus DeepSDF-synthesized shapes from OakInk's Ink), so sampled objects remain plausible for single-hand grasping.

The core novelty is asynchronous denoising schedulers: independent time steps t_H and t_O control the noise level of the hand and object latents. During training, three losses are combined: an unconditional loss on HOI pairs (both latents noised), a conditional loss where the object latent is clean (t_O = 0) and serves as the condition, mixed 1:1 in the spirit of classifier-free guidance but with the condition living in the input/output latent rather than a separate vector, and an object-only loss that supervises just the object slots with the hand slots filled by Gaussian noise, enabling training on object datasets without grasps. Additional HOI-data losses supervise a contact-oriented distance field (vectors between each of 16 hand joints and the 10 closest object points, y_f in R16x30) and MANO joint positions after linear blend skinning. At sampling, joint generation synchronizes the schedulers, while object-conditioned generation keeps t_O = 0 and concatenates the encoded object latent throughout the T-step denoising. Grasps can then be rendered and used as geometry conditions for text-to-image generation (demonstrated with Adobe Firefly), reducing finger artifacts and improving hand-object alignment.

## Contributions

1. A multi-modal latent diffusion model, MGD, that generates hand and object jointly or hand conditioned on object with a single model, without optimization post-processing, category labels, or text conditions, and with MANO hands rather than robotic hand models.
2. Asynchronous denoising schedulers that decouple the noise levels of the two modalities, claimed as the first use of this strategy to stabilize training with unpaired, heterogeneous, partially annotated data (object-only samples supervise only the object slots).
3. A universal grasp generation recipe that borrows object encoding/decoding from LION pre-trained on large-scale object datasets, relieving the object-diversity limitation of HOI datasets; ablations show object-only data improves generalization to unseen objects even without any grasp annotations.
4. Demonstration of downstream use of generated 3D grasps as conditions for photo-realistic image generation with improved geometry consistency and fewer hand artifacts.

## Experimental Setup

Training combines GRAB (51 objects, 1.3k real MANO grasps, hands extracted from SMPL-X, contact-free frames filtered), OakInk-Image (100 objects, 49k grasps), OakInk-Shape (1,700 objects, real plus synthetic grasps, official training split, contact-adapted synthetic grasps included), AffordPose (641 objects, 26k synthetic GraspIt grasps), and DexGraspNet (5,355 objects, 1.32M ShadowHand grasps used for object shapes), plus ShapeNet (51,300 objects) for object-only training and LION pre-training; per-category DeepSDF models from OakInk provide additional synthetic objects. ARCTIC is held out entirely for evaluating generalization to unseen objects. Hands are transformed to the object-centric frame; 2,048 points are sampled per object (uniformly from mesh surfaces for OakInk-Shape). The denoiser follows MDM's transformer encoder-only backbone with 512-d latents. Evaluation uses the OakInk-Shape test set following its metric suite: FID computed between renderings of ground-truth and generated grasps (since no standard 3D generative encoder exists), mesh penetration depth, solid intersection volume, and mean simulation displacement, plus a user study in which 15 participants score batches mixing 10 ground-truth and 10 generated renderings on a 1-5 plausibility scale. Baselines are GrabNet and GrabNet-Refine trained on the GRAB and OakInk-Shape training splits.

## Results

On OakInk-Shape test objects (conditional generation), MGD achieves FID 20.73, penetration depth 0.32 cm, intersection volume 3.87 cm3, mean simulation displacement 2.52 cm, and user score 4.87, versus GrabNet (26.96, 0.70 cm, 11.93 cm3, 3.14 cm, 3.80) and GrabNet-Refine (25.26, 0.63 cm, 4.44 cm3, 2.78 cm, 4.00), a nearly 50% penetration-depth improvement. On objects generated by MGD itself (out of the training domain), GrabNet-Refine collapses to penetration depth 1.17 cm, volume 13.82 cm3, displacement 10.03 cm, and user score 1.33, while MGD's unconditional mode attains 0.51 cm, 6.71 cm3, 7.13 cm, and 3.53, on par with GrabNet's object-conditioned quality. Ablations on unseen ARCTIC objects show monotonic gains from data fusion: training on OakInk-Shape alone gives FID 27.29 / depth 0.51 cm / volume 4.89 cm3 / displacement 3.22 cm / score 3.87; adding GRAB improves to 25.31 / 0.47 / 4.61 / 3.08 / 4.00; adding object-only data further improves to 23.92 / 0.42 / 4.55 / 2.91 / 4.13. For joint (unconditional) generation, the same data progression improves penetration depth from 0.92 to 0.43 cm, intersection volume from 8.12 to 5.55 cm3, displacement from 8.23 to 6.98 cm, and user score from 3.33 to 3.73. Removing the asynchronous schedulers degrades joint-generation quality from 0.43/5.55/6.98 to 0.57/6.52/7.88 (depth/volume/displacement), confirming that decoupled noise levels help the object modality learn independently of HOI-paired supervision. Qualitatively, the model produces diverse grasp patterns on unseen objects, including patterns absent from training data such as holding a dagger between two fingers.

## Limitations

The supplementary failure analysis identifies three failure patterns on unseen objects: hand and object with no contact, twisted hand skin or poses that violate common-sense grasping, and mesh penetration/intersection. The authors attribute these to the lack of explicit contact supervision (such annotations are rare across data sources and expensive to compute), the absence of physics-aware supervision such as simulator demonstrations, and the point-cloud object representation, which leaves the object mesh ambiguous and allows penetration; they estimate such failures at less than 10% of generated samples. Unconditional joint generation is measurably inferior to object-conditioned generation (e.g., user score 3.53 versus 4.87 on the respective evaluations), which the authors note reveals the in-domain bias of HOI test data. Generated object shapes lack the fine carving detail of scanned objects, partly due to the naive Alpha Shape surface reconstruction, and category-prior reconstruction methods cannot be used because the model is deliberately geometry-only. The paper also reports that evaluation of generative grasp quality is inherently difficult (FID on renderings is a proxy), and the user study involves 15 participants rating rendered batches, which is a limited sample.
