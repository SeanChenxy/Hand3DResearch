# HandOccNet: Occlusion-Robust 3D Hand Mesh Estimation Network

**Authors:** JoonKyu Park, Yeonguk Oh, Gyeongsik Moon, Hongsuk Choi, Kyoung Mu Lee  
**Date:** 2022-03-28  
**Identifier:** [arXiv:2203.14564](https://arxiv.org/abs/2203.14564)

## Summary

HandOccNet estimates a full 3D hand mesh (778 vertices via MANO) from a single RGB image, targeting cases where the hand is severely occluded by an interacting object, on the observation that occluded regions carry strong correlations with the hand that prior methods discard. Instead of suppressing features at low-attention locations as conventional spatial attention does, it splits the backbone feature map into primary features (hand regions) and secondary features (occluded regions) using an unsupervised necessity map, then applies two successive Transformer-based modules: a feature injecting transformer (FIT) that computes correlations between primary and secondary features and injects hand information into occluded locations, and a self-enhancing transformer (SET) that refines FIT's output with self-attention, followed by a regressor that outputs MANO pose and shape parameters and the mesh. On HO-3D, HandOccNet reaches Procrustes-aligned joint error 9.1 mm and mesh error 8.8 mm with F@5 56.4 and F@15 96.3, ahead of Liu et al. (10.2/9.8/52.9/95.0), METRO, Hampali et al., Hasson et al., I2L-MeshNet, and Pose2Mesh; on FPHA it reports 10.8 mm Procrustes-aligned mean joint error versus 14.9 mm for the best prior method (Hasson et al.), with code released at github.com/namepllet/HandOccNet.

## Background and Problem

3D hand mesh estimation from a single RGB image has progressed quickly, but occlusion robustness remains an open challenge. Some methods apply the spatial attention mechanism used in 2D human body pose estimation, multiplying an attention map with the feature map to emphasize human regions; the paper identifies two limitations when this is carried to 3D hands. First, the mechanism was designed for 2D body joint localization, and its validity for occlusion-robust 3D hand mesh estimation is unproven — hands have complex articulations and are often severely occluded by objects, so it might fail. Second, severe occlusions make the spatial attention activations sparse, and these sparse regions contain limited information of the hand, so relying only on them can lead to erroneous results. Where prior occlusion-robust pose work relies on occlusion-aware data augmentation (black shapes from Pascal VOC 2012, copied background patches, masked 2D heatmaps), temporal information from video, or spatial attention that discards occluded-region features, HandOccNet treats those features as a secondary information source: secondary features (low attention scores) are leveraged to find relevant primary features (high attention scores) and receive their injected information at empty locations. The injected features serve the 3D hand mesh estimation, in contrast to Liu et al. (CVPR 2021), whose contextual reasoning module enhances object features only for the 6D object pose estimation.

## Method

The pipeline consists of backbone, FIT, SET, and regressor. A ResNet50-based FPN takes a 512x512x3 hand image and produces a feature map F of size 32x32x256; three consecutive convolution layers followed by a sigmoid estimate a necessity map M without supervision, scoring the spatially varying importance of each feature location caused by redundant (background) information, and F is split with sum-to-one constraints into primary feature F_P = F ⊗ M (hand regions) and secondary feature F_S = F ⊗ (1 − M) (occluded regions).

FIT injects primary information into secondary features through two attention sub-modules. The softmax-based attention module extracts a query q_soft from F_S and a key k_soft from F_P by 1x1 convolutions and reshaping to 1024x256 (1024 = 32x32), producing the correlation map C_soft = softmax(q_soft k_soft^T / sqrt(256)). Because softmax normalization considers all elements, an undesirable high correlation can occur when absolute multiplication values are low but relatively large among themselves (for example, background information in the secondary feature unrelated to F_P). The sigmoid-based attention module filters these undesired high correlations: C_sig = sigmoid(pool(q_sig k_sig^T / sqrt(256))) with q_sig and k_sig extracted from F_S and F_P, where pool is average pooling over the key dimension, making correlations robust to noisy values; sigmoid normalizes each element independently and thus avoids the softmax problem. The final correlation map is C = C_soft ⊗ C_sig (1024x1024). The value v comes from F_P via a 1x1 convolution and flattening, giving the residual feature R_FIT = Cv, which a feed-forward module (two-layer MLP with layer normalization and a residual connection between input and output) processes; a further residual connection to F_P yields F_FIT = F_P + ψ(R_FIT + ψ(MLP(LN(R_FIT)))) of size 32x32x256. Notably, FIT removes the standard Transformer residual connection between the input queries and the output: queries are used only for correlation computation, because the goal is to "replace" the secondary features with primary-feature information rather than merely enhance them.

SET refines F_FIT by self-attention over F_FIT itself, with query, key, and value all extracted by three 1x1 convolutions. It uses only the softmax-based attention module — in self-attention every key pixel is at least correlated to its own query, so the undesired-high-correlation problem does not arise — and keeps the standard Transformer residual connection, since its goal is enhancing the input rather than injection. One SET is used after FIT because two or more SETs do not have much effect once sufficient enhancement has occurred in the first.

The regressor produces MANO parameters: a single block of hourglass network takes F_SET and outputs 2D heatmaps for each joint; residual blocks take the enhanced hand feature and the heatmap, and the output residual blocks are vectorized to a 2048-dimensional vector passed through fully connected layers to predict MANO pose θ ∈ R^48 and shape β ∈ R^10. Multiplying the pose parameters by a joint regression matrix to the rest pose and applying forward kinematics yields the 3D joints, and the final mesh V ∈ R^778×3 is obtained by forwarding the MANO parameters to the MANO layer. Training minimizes L2 distances between predictions and ground truths of H, θ, β, and J^3D, where J^3D denotes 3D joint coordinates obtained by multiplying a joint regression matrix to the 3D hand mesh V. All implementations use PyTorch with the Adam optimizer, batch size 24, and learning rate annealed at every 10th from the initial 1e-4 on HO-3D and FPHA; remaining details are deferred to the released code.

## Contributions

- HandOccNet, a novel framework for occlusion-robust 3D hand mesh estimation from a single RGB image, built around a feature injection mechanism that makes the feature map robust to occlusion by properly injecting hand information into occluded regions.
- Two Transformer-based modules for the injection and refinement: FIT performs the injection under the guidance of correlations between primary features (hand regions) and secondary features (occluded regions), and SET refines the output of FIT using a self-attention mechanism.
- Demonstration that the framework significantly outperforms state-of-the-art 3D hand mesh estimation methods on hand-object interaction datasets containing severe hand occlusions (HO-3D and FPHA).

## Experimental Setup

Evaluation uses two hand-object interaction datasets. HO-3D contains RGB images with MANO-based hand joints, meshes, and camera parameters under challenging occlusions; test-set results come from the official online submission system. First-Person Hand Action (FPHA) contains egocentric RGB-D videos of a wide range of hand-object interactions, with 3D hand pose annotations in all frames and 6D object pose annotations in a small subset; HandOccNet follows the same train and test split as previous work (Hasson et al. and Liu et al.). For HO-3D the metrics are the standard mean joint error and mesh error in mm plus F@5 and F@15 from the official evaluation server; for FPHA the mean joint error in mm is reported. All metrics are computed after Procrustes alignment, and joint errors before Procrustes alignment on HO-3D appear in the supplementary material. Ablations on HO-3D cover (1) the overall architecture (identity, residual blocks, FIT only, SET only, FIT+SET), (2) FIT attention designs (softmax only, two softmax modules, softmax plus sigmoid), (3) residual connections between query and FIT output (with q_soft, with q_sig, or none), and (4) SET architecture (identity, residual blocks, single Transformer, two Transformers). Code is available at github.com/namepllet/HandOccNet.

## Results

- HO-3D (Procrustes-aligned, Table 5): HandOccNet reaches joint error 9.1 mm, mesh error 8.8 mm, F@5 56.4, and F@15 96.3, versus Liu et al. (10.2/9.8/52.9/95.0), METRO (10.4/11.1/48.4/94.6), Hampali et al. (10.7/10.6/50.6/94.2 and 11.1/10.0/40.0/93.0), Hasson et al. (11.4/11.4/42.8/93.2), I2L-MeshNet (11.6/13.8/46.9/87.2), and Pose2Mesh (12.5/12.7/44.1/90.9).
- FPHA (Procrustes-aligned 3D joint error, Table 6): 10.8 mm, versus Hasson et al. (14.9 mm), Liu et al. (16.0 mm), Hasson et al. (18.0 mm), and I2L-MeshNet (21.2 mm).
- Architecture ablation (Table 1, Joint/Mesh/F@5/F@15): bypassing the new modules with identity or residual blocks gives 10.6/10.0/52.5/94.9 and 10.2/9.8/51.0/93.3; FIT alone gives 9.4/9.2/54.3/96.0 and SET alone 9.8/9.6/52.6/93.3; combining FIT+SET gives the best 9.1/8.8/56.4/96.3.
- FIT design ablations: softmax plus sigmoid (9.1/8.8/56.4/96.3) beats softmax only (9.5/9.1/54.5/95.9) and two softmax modules (9.6/9.2/53.6/95.9), which the authors attribute to the sigmoid module filtering undesired high softmax correlations; removing the query-output residual connections in FIT (9.1/8.8/56.4/96.3) beats keeping a residual on q_soft (9.5/9.1/55.0/96.0) or q_sig (9.7/9.3/53.3/95.7), consistent with the replacement semantics of feature injection.
- SET design ablation (Table 4): a single Transformer gives 9.1/8.8/56.4/96.3, identity and residual-block variants give 9.4/9.2/54.3/96.0 and 9.6/9.2/54.4/95.9, and two Transformers give slightly worse 9.2/8.9/56.2/96.3 because a single Transformer already enhances the feature sufficiently.
- Qualitatively (Figures 6-8), FIT recovers hand information at occluded locations — producing solid activation in the feature visualization — SET further enriches the representation, and the rendered meshes compare favorably with Hasson et al. and Liu et al. under severe occlusion; comparisons on the larger Dex-YCB dataset are stated to appear in the supplementary material.

## Limitations

The paper contains no dedicated limitations section, so only its own statements can be cited as caveats. The authors acknowledge that a purely softmax-based attention design suffers from undesired high correlations when overall key information is unrelated to a specific query pixel (for example, background content in the secondary feature), which is why the sigmoid-based module is needed, and that stacking two or more SETs yields only marginal benefit because sufficient enhancement occurs in the first one. The main-paper evaluation is limited to Procrustes-aligned metrics on HO-3D and FPHA — pre-alignment HO-3D joint errors and the Dex-YCB comparison are deferred to the supplementary material — and FPHA evaluation covers only the mean joint error (pose), since 6D object pose annotations exist for only a small subset of that dataset.
